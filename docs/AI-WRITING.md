# AI 中文写作规则

2026-11-05。`ai_writing.py` 将本机已审阅的 `human-writing` Skill 的“文件或嵌入处理”模式转成可随应用部署的规则，入口 `ai.generate()` 自动应用。服务器不依赖开发机的 Skill 路径，也不执行从 GitHub 下载的指令。

覆盖主题生成、主题分析、小组回顾、作品深读、作品推荐、读前/观前导赏、本人书评/影评整理、个人笔记提炼、店主邀约/告示、店内活动回顾。新增任务必须选择写作配置，否则拒绝生成；测试会核对任务表和配置表一致。

通用规则保护事实、数字、专名、逐字引语、来源 ID、观点与限定，在同一次生成里做终稿检查，删除助手开场、无依据的宣传腔、重复结尾和凑字数的模板。保留语境成立的专业词、幽默和正常修辞，不做机械敏感词替换，不伪造亲历，不追求检测器分数。JSON 字段和各任务证据校验不受文风规则影响。没有追加第二次模型调用。

书店文案额外传入真实目录的选书方向、介绍，以及管理者保存的“书店语气”。该字段最多 600 字，限本店管理者读写，采用版本校验避免多人覆盖。书店资料仅影响表达，不能当作活动现场材料；回顾仍只采用主持记录与读者明确允许使用的留言。店主语气中的内容仍被当作不可信数据，不得覆盖系统规则或扩展权限。

测试核验所有任务实际请求携带规则、一次调用不增加费用、JSON 合同保持、引用逐字不变、越权编辑与版本冲突。自动测试能验证接入和事实约束，不能证明每一次输出都自然；生成结果继续以可编辑草稿交给使用者确认。
