# 书店圈功能：关注、荐书、再约

2026-11-05。接入既有原生微信小程序和独立书店体验服务，版本目标 1.5.0。

## 行为

- 已登录成员可关注全国任一已收录书店；关注仅持久化公开动态偏好，不加入读者圈，也不获得店主管理权。
- 「我关注的」汇合公开话题、公开邀约和告示、书店上新。圈内帖子、置顶、圈友专场不会进入该列表，即使当前读者已入圈。按稳定游标翻页。
- 荐书从既有全组书目中选择，写最多 140 字理由，可关联书店。服务端从原有书目接口核对书籍标识，保存书名和作者快照；客户端传入的书名不被信任。重复提交同一个请求不会新增第二帖，修改同一已成功请求会提示冲突。
- 本店管理者可以从活动详情或管理页「再约一场」。保留原可见范围，预填标题、介绍、地点和人数，日期重置为下一天并由店主确认。服务端核对原活动、原书店与版本。新活动拥有独立 ID，不复制报名、登录票据、读者感想、AI 回顾。
- 登录页与活动首页保持已确认布局。《书店》仅用于关注空状态；《帕特森》位于荐书表单上方；《海街日记》仅用于新邀约发布成功页。

## 存储与边界

在隔离书店 SQLite 中新增 `shop_follow`、`book_recommendation`、`gathering_repeat`。创建可重复执行，不改写既有帖子和报名。推荐书目由现有主服务 `/api/booklists/group` 提供，隔离服务只转出书名、作者及选择标识。没有新增登录方式、密钥、权限授予或外部服务集成。

沿用原登录要求、到店码验证、角色检查和请求来源检查。关注不发送通知；群分享仍由用户在微信里主动完成。

## 验收与发布

- 验证关注跨用户隔离、持久化、重复操作和私密内容不进入关注列表。
- 验证荐书来源核对、长度、跨城市归属、重复提交及失败后草稿保留。
- 验证再约权限、源版本冲突、圈内可见性和报名不继承。
- 验证旧库升级、原客户端兼容、新页面登录保护、WXML/WXSS 编译和模拟器实际显示。
- 合并此前已完成但尚未部署的活动软删除和有依据的营业时间更新；先备份体验库和旧文件，再更新独立服务，最后上传体验版。不修改主服务网关、成员绑定或店主管理授权。

非目标：自动微信群消息、第三方登录、用户数据迁移到新平台、候补和时间投票。线上真实活动不用于破坏性测试。
