# 实现与验证记录

日期：2026-10-28。以下为当前实现的自审和实际验证，不是独立验收。

## 实现范围

- 单小组账号、管理员创建成员、登录退出、密码修改和成员停用。
- 主题增改、候选启停、权重、随机／避重／延续抽取与抽取历史。
- 主题历史关联，发布时主题和作品快照，草稿／进行中／结束／归档生命周期。
- 作品提名和投票、个人收藏、每周期每成员每作品进度、评价、剧透折叠、讨论状态、请假与不参与。
- 全部／任选作品、评价与讨论要求组合，逾期与补交，归档锁定及归档统计快照。
- 活动回顾、变更后过时提示、JSON 和 CSV 导出。
- Open Library 书名及 ISBN 检索、作品／版本详情、封面；TMDB 电影资料接口；可配置 AI 草稿接口。
- 手机底部导航、成员完成卡片、活动快捷操作、适配弹窗。
- 当前设计以 Criterion 按钮、筛选器和收藏网格为基准；频率 SVG 标志与手写“同频”字标；主题卡使用与主题相关的电影海报。

`npm audit`：已执行并取得 0 个已知漏洞。spin-wheel 的 npm 包包含不使用的可选 Node canvas 依赖，已改用固定版本官方浏览器发行文件；保留 MIT 许可和 SHA-256。

## 浏览器实际操作

在独立的本地演示数据库 `data/preview.sqlite3` 上完成：

1. 登录演示小组，打开主题书架并抽取主题，确认有实际结果和历史记录。
2. 用抽中主题发起活动，选择已刮削的《小王子》，投票并发布。
3. 修复原生日期控件在输入事件中的保存问题，复测截止日保存为 2026-11-15。
4. 登记 100% 进度并提交评价，完成表实际显示 1/1、1 篇评价、已完成。
5. 保存活动回顾、结束和归档；再次查看完成表，操作变为只读。
6. 检查完整封面展示，修复横幅裁切封面的问题。书籍／海报使用 contain，独立电影背景图才裁切。
7. 手机菜单、底部导航、主题卡及完成卡片检查；390px 视口检查未见水平溢出。
8. Criterion 风格筛选面板实际打开；选择“电影”并应用后进入无结果状态，清除筛选恢复作品；切换列表视图、排序“按名称”均改变界面状态。
9. 图标使用 SVG；手写字标为实际路径 SVG，未内嵌 PNG。菜单复用同一资产，避免字重继承变化。

## 数据源实测

- Open Library：真实检索 The Little Prince，取得作者、源作品 ID 和封面；随后取得详情并导入演示库。浏览器检查封面自然宽度为 298px，真实图片已加载。来源数据可能反映具体记录年代；作品级数据不等于特定出版版本。
- ISBN 精确版本入口和元数据映射已实现；特定中文版本覆盖率取决于上游，不能保证每个 ISBN 都有完整简介与封面。
- TMDB：接口映射和未配置提示已测试；没有提供 TMDB_TOKEN，未进行真实授权电影接口验收。
- AI：用户选择稍后配置。完成结构校验和未配置／异常测试，没有调用真实付费模型，不能声称模型输出质量已验收。

## 当前限制

- 单小组、单实例、本地预览；未部署线上。生产 HTTPS、反向代理、备份和管理员恢复仍需部署配置。
- 商业字体 Freight Big Pro / Gotham Narrow 未再分发；使用本地开源字体和明确中文字体映射，不宣称全站逐像素一致。
- 主题海报是人工策展的视觉关联，不能代表成员已看过，也不会自动创建完成记录。海报权利及来源分别记录。
- 手工修订目前按整条作品保护；逐字段锁、多来源自动合并、批量刮削、自动提醒和微信客户端不在本次实现内。
- 参考 Criterion 筛选区域时遇到首次访问 Cookie 提示；默认控件和样式表已读取，站点深层交互未全部操作。没有提交同意条款、登录、订阅或购买。
- 用户已授权初始化仅含 .gitignore 的 main，并推送功能分支创建 PR；演示库与账号资料排除在 Git 之外。
