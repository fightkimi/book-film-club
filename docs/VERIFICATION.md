- 单小组、单实例、本地预览；未部署线上。生产 HTTPS、反向代理、备份和管理员恢复仍需部署配置。
- 商业字体 Freight Big Pro / Gotham Narrow 未再分发；使用本地开源字体和明确中文字体映射，不宣称全站逐像素一致。
