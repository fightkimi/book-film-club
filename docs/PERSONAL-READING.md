# 个人书影与笔记

目标版本 1.6.0，2026-11-05。

## 导航与界面

底部为“活动、书影、树洞、我的”四项。主题收进活动页，发起活动先选主题，挑选的作品可直接带进筹备表单；筹备分成“主题与作品”“时间与参与者”两步，原有抽取、权限、发布与完成要求保留。主题详情和活动详情互相连接到往期讨论。

书影首页只保留记录分类、月份/类型工具栏及列表；空状态只显示一个添加操作。个人微信读书绑定集中在“我的”。月份使用自定义半屏面板，年份居中、双侧切换，月份白底文字，当前选中项深色显示。弹层打开时隐藏底部导航，避免层级相互遮挡。选择作品后收起长列表，直接展示所选作品和计划月份。

## 使用路径

书影页默认显示自己的本月计划、想读想看和已读已看。月份计划与阅读状态独立；重读、重看保留上次的日期和感想。原书影资料库保留为次级入口，作品详情和树洞荐书可加入个人计划。原有成员自己的收藏、导入记录首次打开时迁入，未知完成日期保持空白，不计算为本月完成。

“我的 → 连接我的微信读书”接收本人 Key，校验后同步个人电子书架，书架分组可用于筛选。“有笔记的书”可单独同步笔记目录，包括已不在书架的书。进度同步与手动记录可以切换；手写书评与评分不被远端覆盖。月计划只存在本应用，不向微信读书写入书架、文件夹或笔记。

单本笔记同时读取原文划线和分页的本人想法，按章节、位置排列，保留原文与想法的区别。书签只支持统计数量，接口没有书签内容。选择最多 80 条、总计不超过 60,000 字后主动交给 AI；结果包含主题、要点及可回看的原文证据。生成后的个人修改单独保存。原笔记更新后旧整理保持原样并标记来源变化。

分享是独立步骤：先选择一段，编辑标题、正文和剧透标记，再确认发布到公开树洞或已加入的书店圈。笔记不自动发布；AI 整理的分享标明辅助来源。剧透正文不出现在列表摘要中。关注书店不等于入圈。

## 数据与安全边界

数据位于独立书店服务的 `personal_*` 表，所有查询按已登录成员 ID 限定，平台管理员无跨用户例外。Key 仅短暂存在输入框和请求中，服务端以 AES-GCM 加密，认证附加数据绑定成员；不返回 Key，也不使用原共享书架 Key 自动读取私人笔记。

主密钥位于书店状态目录 `personal-credentials.key`，0600，原子创建；首次绑定前不存在是正常状态。不得丢弃或重建已有密钥。备份数据库时同时备份该文件并限制权限，不能把二者提交到仓库。可通过 `PERSONAL_VAULT_KEY_FILE` 指向同等受保护的位置。

解绑清除凭证、远端书架和原始笔记缓存，保留个人计划、手写感想及已保存的整理（包括其证据快照）。连接代号在提交时再次校验，防止解绑或更换 Key 后旧同步写回。同步和生成在数据库写事务之外执行；同一用户有并发和频率限制。AI 仅接收所选笔记、书名、作者，不接收 Key、微信标识或成员身份信息。

## 来源与验收

接口依据 [腾讯官方 WeRead Skill](https://github.com/Tencent/WeChatReading/tree/main/skills)，当前协议 1.0.5；业务参数平铺，收到 `upgrade_info` 即停止。笔记目录使用 `lastSort`，个人想法使用 `synckey` 翻页。此实现只读，未调用未公开的写接口。

整理方法参考 MIT 项目的设计：[book-learning-skill](https://github.com/mollycall-zmy/book-learning-skill) 的按内容组织与来源证据、[qiaomu-read-helper](https://github.com/joeseesun/qiaomu-read-helper) 的原文与批注分离、[smart-notes-skill](https://github.com/OnePathToFreedom/smart-notes-skill) 的保留用户修改。没有复制它们的代码、安装外部执行器，或接入其自动评论、消息和推送流程。

验收覆盖凭证保密与属主绑定、管理员隔离、旧库重复升级、完成日期与重读历史、全页笔记合并、引文精确匹配、解绑并发、选段确认和圈内权限。自动化使用临时数据及模拟 WeRead/AI 响应；本人实际 Key 与模型文风效果由体验版主动使用时核对，不能把模拟通过当成真实接口已实测。


## 1.6.1 资料与书评

书影资料库、成员书单与选书页点击作品直接进入完整简介。已入库作品使用现有资料；未预载的公开书籍按需通过固定 WeRead 元数据接口读取，个人微信读书书籍使用本人连接读取。个人导入书没有公开简介时不猜测内容。公开资料的加入计划由服务端核对书籍 ID 和来源资料，客户端传来的书名不作为来源。

个人记录页以书评/影评为主要编辑区，进度、评分和月份计划可展开修改。绑定本人连接且存在准确 WeRead 书籍 ID 时，首次打开、连接改变或回到页面超过一分钟后尝试更新划线与想法；有未保存草稿时不自动发起同步，可主动更新。同步只刷新笔记，不覆盖书评。没有精确来源 ID 的记录不会按书名模糊匹配别的版本。

读者勾选笔记并确认后，可用当前草稿与所选笔记辅助写书评。所有生成沿用 human-writing 规则，划线不被当作本人观点；引文校验来源 ID 与逐字原文。AI 输出独立展示，需采用到编辑框后再保存，可恢复采用前原稿。不自动发布或发送到微信群。情节折叠选项仅在分享页出现。

发起活动直接进入筹备表单，主题下拉只列真实主题；随机抽取在表单内完成，不跳转或播放动画。活动里的“主题记录”仅列已关联活动的主题。现有抽取历史与活动权限不删除。
